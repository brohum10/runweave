Evidence, not a black box

The machine-readable result includes each task's status and complete SHA-256 output hash. Run the included script to reproduce it in a temporary workspace. The repository also includes 18 tests for cache invalidation, damaged artifacts, failed tasks, cycles, and unsafe paths.

Read the code and tests ↗

What this does not prove

This is a local synthetic example, not a performance or production reliability benchmark.

  • Scripts must be trusted and deterministic.
  • All output-affecting inputs must be declared.
  • A hash checks bytes; it does not prove correctness.
